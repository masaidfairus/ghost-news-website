# From the Other Side

A platform for sharing ghostly encounters. This web application allows users to view news articles, report ghost sightings, and explore a collection of paranormal stories.

## Features

- View paranormal news articles
- Report and browse ghost sightings
- Upload sighting details with images
- Browse a collection of ghost stories

## Installation

1. Clone the repository or download the project files.
2. Navigate to the project directory.
3. Install dependencies:

   ```bash
   npm install
   ```

## Running the Application

To start the server:

```bash
npm start
```

For development with auto-restart:

```bash
npm run dev
```

The server will run on `http://localhost:3000` (or the port specified in server.js).

## Project Structure

- `server.js`: Main server file
- `public/`: Static files (HTML, CSS, JS)
- `data/`: Data files and stories
- `handlers/`: Route handlers
- `utils/`: Utility functions
- `events/`: Event handling for sightings

## Technologies Used

- Node.js
- HTML/CSS/JavaScript
- sanitize-html for input sanitization
